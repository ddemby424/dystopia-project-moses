🧪 How to test a change

  1. Open the file, press Ctrl+F, paste the green text.
  2. Change only the number.
  3. Ctrl+S to save.
  4. Spck: tap ▶ preview (or Ctrl+Shift+P). Already open? Pull down to refresh, or close and reopen preview.
  5. Skip the trailer, start, look for the change.

Black screen or stuck loading? You broke a comma or bracket. Undo (below) and try again.

👀 Win: you see your change in the game.

↩️ How to undo

  • Right away: Ctrl+Z until it's back, then save.
  • Write the old value down (or put it in a comment: walkSpeed: 20, // was 14... careful, only after the comma).
  • Keep a copy: long-press game.js → Duplicate before big edits.
  • Reset a file to GitHub's version: Spck Git menu → Changes → tap the file → Discard/Revert. That is the same as git restore game.js.
  • Already pushed something bad? Ask Grok Bot to roll it back.

⚠️ Rules so nothing breaks

  • Change numbers, colours and text in quotes. Don't rename functions or names before a :.
  • Keep every , ; { } [ ] ( ) and quote mark.
  • Colours in game.js look like 0xff4400. In style.css they look like #ff4400.
  • Text with an apostrophe inside '...' needs \'.
  • IS_COARSE ? A : B means "phone/tablet uses A, PC uses B". Your Fold uses the first number.
  • One change at a time. Test. Then the next one.

📦 Adding assets, step by step

A1. Which folder

Put files here (lowercase names, no spaces): models/ 3D (.glb) · images/tex/ textures (.jpg/.png) · audio/ short sounds (.mp3) · music/ songs (.mp3) · media/ video (.mp4) · fonts/ (.woff2).

A2. Formats + phone budget

Use .glb (one file; .gltf needs its extra files too). Textures .jpg (photos) or .png (see-through), 1024×1024 max. Sounds .mp3 (works on iPhone; .ogg does NOT play on iPhone Safari). Budget per model: under 1.5 MB and under ~15,000 triangles. Characters up to ~25k. Shrink big ones (see the Android tutorial, A4).

A10. Upload the file in Spck

Spck file tree → long-press the models folder → Import / Upload file → pick from Downloads. Then Git → Changes → tick the new file + game.js → Commit with a message → Push. Live in ~1 minute.

A11. Common mistakes

  • Case matters online: Cone.glb ≠ cone.glb. Works in preview, breaks live.
  • Path is relative to index.html: models/cone.glb, never /sdcard/… or C:\.
  • Opening index.html from the Files app (file://) blocks model loading (CORS). Use Spck preview.
  • Forgot the comma at the end of the jobs line → black screen.
  • Big file (10 MB+) → slow load, phone crashes. Shrink first.
  • Model is sideways? add yaw: Math.PI / 2 to its jobs line.

M8. New HTML pages

Any .html you add is a web page at …/dystopia-project-moses/yourpage.html. Copy learn-3d-112248cf/step1.html as a template. Link to it from anywhere with <a href="yourpage.html">.

M9. What NOT to touch

  • Don't rename game.js functions or top-level names (STATE, BOTS…) — other code calls them.
  • Don't delete or rename an id="…" in index.html — game.js looks them up.
  • Don't edit tools/ or regression-out/ from Spck.
  • Never paste tokens or API keys into a file (the Meshy key lives only in the browser).
  • Mods can't change const numbers inside functions — for those, edit game.js (see the tweak cards).
