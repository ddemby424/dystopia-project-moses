Work on DYSTOPIA on your Android tablet

For the Lenovo tablet + Targus keyboard. Tiny steps, each ends with a 👀 win. Two apps are covered: Spck Editor (has Git built in, the easiest way to push) and Acode (great editor, uses a plugin for GitHub). Pick one. If unsure, pick Spck.

👀 Win: code on the left, game on the right.

0. Words you'll see

  • Repo = the project folder on GitHub. Clone = copy it onto the tablet.
  • Commit = a save point with a note. Push = send commits to GitHub; the live game updates in about 1 minute.
  • Token = a long password made only for one app. You can cancel it any time.

Part 1: Install

1. Get the app from the Play Store

Play Store → search Spck Editor (by Spck, "Spck Editor / Git Client") or Acode → Install. The free versions are enough.

👀 Win: the app opens to its project/file screen.

Part 2: A GitHub token (the safe way)

2. Make a token

In Chrome, sign in to GitHub, then open github.com/settings/personal-access-tokens/new (fine-grained token).

  1. Name: tablet-spck (or tablet-acode).
  2. Expiration: 90 days.
  3. Repository access: Only select repositories → dystopia-project-moses.
  4. Permissions → Repository: Contents: Read and write (Metadata: Read is added for you). Spck's own link also adds Pull requests: Read and write; that's optional.
  5. Generate token, then copy it right away. GitHub shows it only once.

🔒 Safety rules: paste it only into the app's credentials box. Never into chat (not even to Grok Bot), email, a code file, or a screenshot. If it ever leaks: GitHub → Settings → Developer settings → Personal access tokens → Delete, then make a new one.

👀 Win: a token starting with github_pat_ on your clipboard.

Part 3: Get the code

3S. Spck: save the token, then clone

Spck: Git menu → Git Credentials → choose GitHub → paste the token → save.

Then create a project by cloning: on the project screen pick the clone option and paste

https://github.com/ddemby424/dystopia-project-moses.git

Keep the project in device storage. Spck's Git needs a real device folder.

👀 Win: the project opens and you see index.html, game.js…

3A. Acode, option 1: GitHub plugin

Acode: menu (top-left) → Extensions icon → search GitHub → Install. Tap the GitHub icon in the sidebar → Sign in with GitHub (or Use personal access token and paste yours) → pick dystopia-project-moses → branch main. It opens as a folder.

This plugin edits the repo directly on GitHub. Every save becomes a commit (it asks for a message). No separate push step. The flip side: every save goes live.

👀 Win: the repo files appear in Acode's sidebar.

3A. Acode, option 2: ZIP (read and tinker only)

In Chrome open the repo → Code → Download ZIP. Open the Files app → Downloads → tap the ZIP → Extract. In Acode: menu → Open Folder → pick the extracted folder.

⚠️ A ZIP copy can't push. Use it to experiment, then make the real change with option 1 or Spck.

Part 4: Run it on the tablet

5. Why tapping index.html in Files fails

Opening the file straight from Files gives a file:// or content:// address. Browsers won't let that page load other files, so the models and textures don't load (stuck loading bar, grey boxes). You need the app's little web server.

6S. Spck preview

Open index.html and tap the preview (play) button, or press Ctrl+Shift+P. In Settings → Tablet Mode you get editor and preview side by side; Live Preview refreshes it when the code changes.

👀 Win: DYSTOPIA runs inside Spck.

6A. Acode preview

Open index.html and press F5 (or tap the ▶ run button at the top). Acode serves the folder and opens a preview; from its menu you can open it in Chrome.

Want auto-reload? The Live Server plugin (Extensions → search "Live Server") does that, but it needs Termux running a small server too. It's optional; F5 is enough.

⚠️ With the GitHub plugin (3A option 1) the files live on GitHub, not on the tablet, so preview may not load the models. Check on the live site after saving (step 20).

7. Editor + game side by side

Open the preview in Chrome, then use split screen (cheat sheet) or Alt+Tab to hop between them. After saving, refresh Chrome.

Part 5: Change common things

8. Find anything

Open game.js, press Ctrl+F (or the 🔍 icon), type a word below. Both apps also search the whole project from the side menu.

walkSpeed: 14          player run speed (try 20)
jumpVel: 8.5           jump height
weapons: [             all guns: damage, ammo, fireRate, spread

Part 6: Assets (models, pictures, sounds)

Getting files onto the tablet: download in Chrome, then move them with the Files app into the project's folder (e.g. models/). In Spck you can also import files into the project. With the Acode GitHub plugin, create the file in the right folder from the plugin's file browser.

A1. Where each kind lives

3D models (.glb)        models/          e.g. models/ph_power_box.glb
Textures (.jpg)         images/tex/      e.g. images/tex/metal_wall_1k.jpg
Sounds, voices (.mp3)   audio/           e.g. audio/colossus_loved.mp3
Music (.mp3)            music/
Video (.mp4)            media/           media/dystopia_trailer_720p.mp4
Fonts (.woff2)          fonts/           + the licence .txt next to it

A2. Naming rules

  • all lowercase, words joined with _: crate_metal.glb ✅ Crate Metal(1).GLB ❌
  • no spaces (the live site is picky about case: Crate.glb ≠ crate.glb)
  • textures end in their size: _1k.jpg
  • prefix by source if you like: ph_ = Poly Haven, pp_ = Poly Pizza

A3. Phone budget (so it stays smooth)

One prop          under 5,000 triangles,  under 500 KB
One enemy model   under 20,000 triangles, under 2 MB
Textures          1024×1024 (1K) max, .jpg (or .png only if it needs see-through)
Sounds            .mp3, under 200 KB each
Music             .mp3, 128 kbps

Check a model: drag it onto gltf-viewer.donmccurdy.com. It shows size and triangles.

A4. Shrink a big model (1 command)

⚠️ This needs a computer (or Termux). On the tablet: ask Grok Bot to shrink it for you. The command it runs:

npx @gltf-transform/cli optimize models/big.glb models/crate_metal.glb --texture-compress webp --texture-size 1024 --simplify-ratio 0.25

0.25 keeps a quarter of the triangles. Too blobby? Try 0.5.

👀 Win: the new file is much smaller. Check it in the viewer from step A3.

A5. Worked example: add a new 3D prop

A5a. Drop the file in. Download a model (e.g. a crate from Poly Pizza, or one you made on Meshy). Rename it crate_metal.glb, put it in models/.

A5b. Add it to the loader list. In game.js, Ctrl+F → const jobs = [. Find the ph_airduct line and add ONE line under it:

    { file: 'models/ph_airduct.glb', role: 'prop:ph_airduct', height: 0.75 },
    { file: 'models/crate_metal.glb', role: 'prop:crate_metal', height: 1.0 },

height = how tall it ends up in metres (the game auto-scales it). The part after prop: is its nickname.

A5c. Teach the game how to build it. Ctrl+F → const PROP_BUILDERS = {. Paste this right after that line:

  crate(o) {
    const g = new THREE.Group();
    const c = cloneProp('crate_metal');               // the nickname from A5b
    if (c) {
      c.position.set(0, 0, 0);                        // nudge: x, up, z (metres)
      c.scale.setScalar(o.scale || 1);                // bigger: { scale: 1.5 }
      g.add(c);
    }
    return { g, collide: null };
  },

A5d. Place it in a level. Ctrl+F → add('powerbox', 3.95, 60.5. On a new line under it paste:

    add('crate', 3.0, 58.0, { rot: Math.PI / 4, scale: 1.2 });

3.0, 58.0 = x and z on the floor map. rot = turn in radians (Math.PI / 2 = 90°, Math.PI = 180°), just like TI-89 radian mode.

👀 Win: Ctrl+S, refresh the preview (Part 4), walk to that spot: your crate is there.

🧪 Try: change rot to Math.PI and scale to 2.

A6. Add a sound

Put alarm_beep.mp3 in audio/. Anywhere you want it to play (e.g. inside a function that runs on an event), paste:

try { if (!SFX.muted) { const a = new Audio('audio/alarm_beep.mp3'); a.volume = 0.8; a.play().catch(() => {}); } } catch (e) {}

This is the same pattern the game uses for audio/sentinel_dispatch.mp3 (search it to see).

👀 Win: you hear it when that event happens.

A7. Swap a texture

Make your picture 1024×1024, save as images/tex/rust_wall_1k.jpg. In game.js Ctrl+F → metal_wall_1k.jpg and change just the filename:

swap(WALL_PBR.map, 'images/tex/rust_wall_1k.jpg', '#4a5670', true, 3);

👀 Win: every wall now wears your texture.

A8. Credit it (every time)

Open CREDITS.md and add one line, e.g.:

- "Metal Crate" by SomeArtist via Poly Pizza, CC BY 3.0 — models/crate_metal.glb

CC0 = no credit needed (still nice). CC BY = you must credit: also add it to the in-game screen (Ctrl+F → CREDITS_HTML). "NC" or "ND" licences: skip that asset.

A9. Test, then publish

Check it in the preview (Part 4). Looks good? Commit and push (Part 7).

Part 7: Commit and push

18S. Spck

Ctrl+S to save. Git menu → Commit (or Ctrl+Shift+C), type a note like Faster walk speed, commit. Then Git menu → Push.

18A. Acode

With the GitHub plugin, Ctrl+S is the commit: type a message when it asks. Done.

19. See it live

Wait about 1 minute, open the live game, refresh.

👀 Win: your change is live for everyone.

Part 8: The test robot

20. Ask Grok Bot to run the tests

node tools/regression.js needs Node.js and a desktop Chrome. That doesn't run on the tablet (only with a lot of Termux setup). After you push, just say: "run the regression", and Grok Bot will run all 264 checks and tell you what passed or broke.
