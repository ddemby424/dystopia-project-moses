# Simple FPS: 3 rooms + 1 hall

One file: `index.html`. Open it in Spck/Acode and press Run/Preview (needs internet, since three.js loads from a CDN).

Map: Room A (start), then a hall, then Room B, with Room C (the enemy) through a door on the right.

| Action | Keyboard | Touch |
|---|---|---|
| Forward / back | W/S or ↑/↓ | ▲ / ▼ |
| Strafe | A / D | – |
| Turn left / right | Q/E or ←/→ | ⟲ / ⟳ |
| Look | mouse (click to lock) | drag the screen |
| Shoot | click | FIRE |

Search `<<<` in the code to find the key lines: placement, spawn, turn, forward and speeds.
