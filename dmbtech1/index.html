ENGINE · V1.0.1

DMB TECH 1

A standalone 3D first-person engine for the browser. Load a .retro map, walk, shoot, and hook events — no editor required, and no build step.

Play the minimal example Download v1.0.1 zip README

Examples

  • Minimal — smallest playable game, loads a bundled map.
  • Custom weapon — registerWeapon and put it in your hands.
  • Level script — map script plus engine.on events.

For developers

  • ES module: import { createEngine, VERSION } from './dmbtech1.js'
  • Peer dependency: Three.js r128, via a pinned import map (see the README).
  • Works in Spck, Acode, and any static host. Serve over HTTP, not file://.
