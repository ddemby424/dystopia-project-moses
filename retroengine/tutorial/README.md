# RetroEngine hands-on tutorial

A bite-size guide for early trial users and for Darcy. Each lesson takes about 5–10 minutes and ends with something you can see or play.

**Engine name:** RetroEngine is the game maker (editor + maps + pack). The 3D game runtime inside it is the **DMB Tech 1** engine layer, built on three.js r128. This tutorial always calls that runtime DMB Tech 1.

**Who it's for:** people opening the trial map pack, and Darcy editing the source on a phone in **Spck Editor** or **Acode** (Android). These lessons do not assume a desktop IDE.

**Live app:** [RetroEngine](https://ddemby424.github.io/dystopia-project-moses/retroengine/) · [Trial map pack](https://ddemby424.github.io/dystopia-project-moses/retroengine/maps/)

**How to read this:** open [`tutorial.html`](tutorial.html) on your phone for the comfortable layout, copy buttons, and jump list. The `.md` files here are the same lessons in plain text.
