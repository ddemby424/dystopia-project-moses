## Original procedural weapons
The default starting firearm is a **Pulse Cannon** built in-engine (no third-party model). It is a compact port of the early DYSTOPIA Version 2 default gun (first shipped in that project on 2026-11-10, git commit `16322b7`). The mesh, the cyan pulse projectile, and the synthesized pulse sound are original work and may be used freely (CC0 / public domain). The Quaternius pistol GLB below remains in the repo but is no longer loaded as the default starting weapon.

## Textures: original (made by RetroEngine)
All 20 wall, floor and ceiling materials are generated by code inside `app.js` when the game starts: Concrete, Bunker Concrete, Grimy Brick, Steel Panels, Tech Wall, Rusted Steel, Floor Grate, Hazard Stripes, Ceramic Tile, Industrial Tile, Tread Plate, Asphalt, Wood Planks, Ceiling Panels, Ceiling Lights, Server Racks, Blast Door, and the Red, Blue and Yellow Key Doors. Their colour, normal (bump) and glow maps are drawn with procedural noise. No image files or third-party textures are used. The sky scenes are generated the same way.

## Props, pickups, turret, effects and sound: original
The 14 props (crates, barrels, pillars, desks, terminals, server racks, pipes, etc.), all pickups and keycards, the Sentry Turret, the fallback enemy robots, particles and every sound effect are built or synthesized by RetroEngine's code (WebAudio). No sound files are used except the music above.
