# DOOMFORGE IDE: browser FPS game maker (v2.0)

DOOMFORGE lets you build gritty, retro-style first-person shooter levels in the browser, play them right away, and export each one as a single HTML game file you can share.
It works with a mouse and keyboard, and fully by touch on phones, foldables (tested on Galaxy Z Fold folded and unfolded) and tablets.

## Files
| File | What it is |
|---|---|
| `fps-game-maker.html` | **The whole app in one file.** Open it in any modern browser. |
| `fps-game-maker.txt` | Byte-for-byte copy of the html, for apps or chats that block .html. Rename it to `.html` to use it. |
| `index.html` + `styles.css` + `app.js` | The same app split into three files, for editing in Spck / Acode / VS Code. |
| `CHANGELOG.md` | What changed. |

The only thing it needs from the internet is **Three.js r128**, the 3D engine, from a CDN (cdnjs, with jsDelivr as a fallback). It caches after the first load. Everything else is generated by code.

## Opening it in Spck or Acode (Android)
1. Copy the `release` folder (or unzip `doomforge-ide-release.zip`) into a Spck/Acode project.
2. Open `index.html` and press **Run/Preview**, or open `fps-game-maker.html` straight in Chrome or Samsung Internet.
3. Your work autosaves in the browser (localStorage). Use **Menu → Projects** for save slots and **Export JSON** for real backups.

## Features
**Editor**
- Tools: Select/Move, Pan, Wall, Floor, Ceiling, Height (stairs, catwalks, cover blocks), Rect, Fill, Erase, Door (plain, or red/blue/yellow keycard), Thing, Player Start, and Picker (eyedropper).
- Undo/redo (100 steps), plus copy, cut and paste of map areas. You can save any selected area as your own template.
- Zoom and pan with pinch, the mouse wheel, Space-drag or the zoom dock. **Fit** frames the whole map.
- **Rooms library: 22 templates.** Rooms, corridors, stairs, and buildings such as Bunker, Guard Tower, Mezzanine Hall, Courtyard, Hangar, Server Room, Reactor and Warehouse. Each stamp has a live preview and can be rotated with **R**.
- Multiple levels per project, plus per-level properties: sky, fog, ambient light, wall height, default textures, music mood and par time.
- The **Validate** check confirms the exit is reachable, keys come before their doors, and the player can't walk off the map.
- Code editor tabs for `level.json`, `script.js` (level scripting) and `project.json`.
- Built-in Help/onboarding and an About & credits page.
- Save and load: autosave, named project slots, JSON import/export, and import of old v1 projects.
- **Export:** a standalone single-file game you can download, copy, or preview in place.

**Game runtime**
- Real-time 3D with Three.js: instanced walls and floors, sliding doors, raised floors and stairs, a sky dome with fog, and coloured point lights.
  There's also a flashlight, muzzle flash, ACES tone mapping and three quality presets.
- 20 procedural gritty PBR-style textures (concrete, rusted metal, tech panels, brick, hazard plates, grates, tiles and more), each with a normal map and an emissive map.
- Weapons: Wrench, Pistol, Shotgun, Pulse Rifle, Plasma and Rocket launcher (with splash damage).
- Enemies: Scout mech (grunt), Drone, Heavy, Turret and Titan boss. They are grounded on the floor, turn to face you, and find their way to you using pathfinding.
  Their AI states are idle, alert, chase, attack, pain and death.
- Pickups: health, armor, ammo, weapons and keycards. 14 props (explosive barrels, crates, lockers, generators, sandbags, lamps and more). Exit pads and secrets.
- HUD, minimap, full map (M), pause menu, and settings (sensitivity, volume, quality, FOV, invert, etc.).
- Touch controls: a floating move stick, a look zone, and FIRE (drag it to aim), JUMP, USE, SWAP and RUN buttons. Pointer lock is used when the browser allows it, with drag-to-look otherwise.
- Sound: a WebAudio synth makes every sound effect and the generative music. No audio files and nothing copyrighted.
- Level scripting with `api` hooks: start, tick, kill, pickup, door, use and exit.
- **3 starter levels:** E1M1 Outpost Breach, E1M2 Server Hall G (catwalks), and E1M3 Foundry Core (Titan boss).

## Controls
**Editor:** V select, H pan, B wall, F floor, C ceiling, U height, R rect (or rotate while stamping), G fill, E erase, D door, T thing, S start, I picker, `[` `]` cycle textures, Ctrl+Z / Ctrl+Y undo/redo, Ctrl+C / X / V, Ctrl+S save, P playtest, 0 fit, ? help. (Each tool button shows its letter.)
**Game:** WASD move, Shift run, Space jump, mouse look and click to shoot, E use, 1-6 or Q / wheel to change weapon, F flashlight, M map, Esc pause.

## 3D models (optional)
The game is complete **without any model files**: every enemy, weapon, prop and pickup is built from code.
In **Project → Models** you can assign your own `.glb` files to slots. They are auto-scaled and grounded. Only use CC0 or CC-BY models, and credit their authors.
Uploaded models are stored inside the project, so big files can fill browser storage. Use models under about 2 MB each.

## Testing
`tests/test_doomforge.py` (included in the zip) runs 50 headless Chrome checks with Playwright. It covers the editor tools, templates, undo, save and load, the playtest (movement, enemies visible, grounded and facing the player, shooting, all weapons, pickups, doors and keycards, AI damage), menus, export, the starter levels, and the folded and unfolded Fold layouts. It also requires zero console errors.

## Known limits
- No overlapping multi-storey floors. Height is one level per cell (stairs, catwalks, raised platforms).
- The 3D engine loads from a CDN, so the very first launch needs internet.
- Some in-app webviews block pointer lock. The game then uses drag-to-look automatically.
- localStorage is about 5-10 MB per site. Export JSON backups regularly, especially when you use GLB uploads.
